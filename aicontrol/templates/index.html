Arms

This page is read-only. Arming, disarming and the rails are on the Control page (:8088/control), the one place a human changes them; no AI tool can. Arms start off every time this service starts and are never saved. Disarming moves nothing — it only stops further AI changes.

Activity

Rails — limits the AI can never change

“—” means not set: for a min / max pair the AI then may not change that quantity at all; for a step, rate, max-open time or arm time it means no limit (except max open, which is needed to open a valve at all). Rails cap what the AI may command; the PV interlock still caps temperature for everyone, and the service also keeps setpoints 5 K inside the interlock band.

Connecting Claude

Claude reaches this service over MCP (Streamable HTTP, JSON responses) at http://xbox-pi:8089/mcp. Add it to Claude Code with
claude mcp add --transport http xsphere http://xbox-pi:8089/mcp
or as a project .mcp.json:

      Better: copy aicontrol/operator/ (in the repo) to
        C:\Users\xbox\xsphere-ai-operator — outside any git repository — and open Claude Code there. Its settings
        allow only the xsphere tools plus reading files, and deny shell, editing, web, browser, terminal and other-session
        tools, so the session cannot go around a refusal. Check it: ask it to run hostname and to open the
        Control page — both must be refused.
